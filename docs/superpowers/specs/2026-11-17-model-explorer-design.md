# 모델 선택 도구 v2 설계

상태: 핵심 설계 사용자 승인(2026-11-17). 후속 답변: 모든 사용자가 볼 수 있도록. 세부 구현 선택은 에이전트 판단이며 출시 성과가 검증된 것은 아니다.

## 목적
일반 사용자와 개발자 모두가 업무별 실측 근거·비용·데이터 공백을 보고 후보 모델을 고르게 한다. 분석은 docs/research/2026-11-17-aa-v5-review.md 참조.

## 접근 비교
- AA 순위표 복제: 구현은 쉽지만 원본 대비 가치가 작고 기존 오류를 반복한다.
- 자체 한국어 종합평가: 장기 차별화가 크지만 검증 데이터·실행 비용·독립 평가 설계가 필요하다.
- 승인된 방향: AA 실측을 한국어로 해석하는 선택 도구. 원본 평가를 재계산하지 않고 근거와 제약을 공개한다.

## 화면
첫 화면은 목적 선택(종합/문서·업무/코딩/과학/빠른 응답), 후보 목록, 비교 선택. 모델 상세·개발자 정보에서 원시 평가값, 단가, 비용 계산을 제공한다. 기본 진입은 v5 실측 비교이며 8축은 별도 레거시 탭으로 이동한다. 현재 데이터에 근거 없는 일상대화·한국어 전용 품질 추천은 하지 않는다.

## 데이터
- 모델 id와 release.slug·추론 변형 보존, name/shortName은 표시용.
- 초기 RSC와 페이지가 해석한 추가 객체를 수집; id와 slug 두 형식 허용.
- 구조화된 scores를 원본 그대로 보존. 지수 버전, 성능 버전, schema_version, 관측 날짜, 출처를 함께 전달.
- 원본 v5 지수·과제당 비용(USD)·시간(초)을 사용하고 결측은 null. 시간 원시 단위는 공식 페이지 표시값과 대조 후 확정.
- 부분 평가를 지수로 추정하지 않는다. 과거 v4 점수와 v5 상승률을 계산하지 않는다.
- 기존 레이더는 구형 평가 기반 자체 상대지표임을 명시. 추천 순서에서 kNN 제외.

## 선택 흐름
목적별 정렬은 실제 대표 벤치마크 하나를 사용하며 그 이름과 단위를 공개한다. 예: 문서 업무 AA-Briefcase Elo, 코딩 FrontierCode2, 과학 Terminal-Bench-Science. 미측정은 아래로 배치. 공식 4개 영역은 그룹으로 보여주고 별도 영역 종합점수는 만들지 않는다.
과제 비용과 지수로 비지배 후보(Pareto)를 표시한다. 동일 지수/비용은 동등 취급; 결측과 0은 구분한다. 토큰 계산은 사용자가 입력한 입·출력량과 단가만으로 계산하고 추론/도구 추가비용 미포함 조건을 밝힌다. 웹 구독료는 API 비용과 혼합하지 않는다.

## 품질 및 배포
핵심 필드·벤치마크 보유 수와 수집 상태를 노출. 필드 전체 소실·과도한 조인 누락·가격 급감은 빌드 실패. 지수 없는 모델을 억지로 0으로 만들지 않는다. 수집 실패는 기존 운영 데이터 보존. 임계값·방법론은 버전과 함께 문서화한다.
기존 GitHub Pages/Node Playwright/Python stdlib 구조 유지. 이번 구현은 로컬에서 검토 가능하게 만들고 실제 배포 전 결과를 제시한다. 외부 계정·유료 API 호출·분석 추적기 추가 없음.

## 단계
1. 데이터 계약 복구: 현재 id·nested release, v5 scores, 비용·시간·성능 필드 및 회귀 테스트.
2. 입문자용 목적 탐색·v5 근거 표·비용 계산·데이터 건강 상태. 구형 레이더를 보조로 유지.
3. 공유 가능한 비교·조건 보존, 다운로드. 같은 버전에서만 변동 비교(향후).
4. 별도 한국어 과업 평가·실사용 사용자 검증(향후, 별도 설계).

## 이번 수용 기준
실제 최신 수집 성공, 데이터 날짜·버전 표시, 목적 변경 시 근거 있는 정렬, 결측 제외 규칙, 단가와 과제 비용의 단위 분리, 좁은 화면 사용 가능, 원본 모델 변형 보존, 새 회귀 테스트 및 기존 테스트 통과.

## 사용자 후속 반영: 제작사 고정·빠른 답변 품질 조건

사용자가 제작사를 직접 고정하고 낮은 품질 모델이 빠른 답변 상위에 나오는 문제를 지적했다. 전체 제작사를 검색 가능한 native dialog 체크리스트에서 고정하며 전체 고정/해제·취소·저장 제공. localStorage에 고정 목록·고정만/전체보기·최소지수를 저장한다. 저장 불가 시 이번 방문만 유지 안내. 제작사 조작 시 다른 필터 유지.
빠른 답변은 AA v5 실측지수≥30(기본 정책, 품질 보증선 아님) 및 유효 첫답변 대기 측정이 있는 후보만 빠른 순으로 정렬한다. 사용자 선택 0/20/30/40/50, 지수 미측정은 항상 제외. 기준을 낮춰도 업무 성공을 보장하지 않음. 첫답변 대기와 전체 완료시간을 구분해 표시.
검증: Node65개 통과, 검색·고정·취소·새로고침·전체보기·품질 저장·단위테스트 포함. 모바일 dialog overflow0 확인. 현재277개 중 빠른 답변 기본조건 후보52개.

# Astryx UI 전환

## 사용자 피드백
기존 UI/UX가 불편하다는 사용자 평가. Meta Astryx 스킬을 명시적으로 요청했다. 일반 사용자 포함이라는 제품 대상, 제작사 고정과 품질 기반 빠른답변 조건 유지.

## 원문과 적용
- 공식 스킬: https://github.com/meta/astryx/blob/main/plugins/astryx/skills/astryx/SKILL.md
- 공식 저장소: https://github.com/meta/astryx
- 프로젝트 안내 생성: docs/astryx-agent.md
- 버전: core/cli/theme-neutral 0.7.16, React19.3.1, 정확 버전 고정.
- `astryx init --features agents --agent-docs-path docs/astryx-agent.md`, `astryx build`, `astryx template library --type page web/App.tsx`, 컴포넌트 문서 조회, `astryx theme add neutral`, doctor 적용.
- library 템플릿의 Layout header/content padding6, VStack gap6, Grid gap4 구조를 유지하고 모델 카탈로그로 교체. 템플릿 미디어·샘플 항목은 사용하지 않음. 라이선스 web/LICENSE.astryx.

## 변경
중복 좌측 목록·상시 우측 점수표를 기본 화면에서 제거. 목적·검색·고정제작사·필터를 상단 배치. 모델별 주요 실측을 Card로 탐색하고 상세/비교는 Dialog. 선택은0~3개, 하단선택바에서 비교. 후보 수 제한 도달 시 메시지. 12개씩 더보기. 제작사 고정·품질조건 설정을 기존 저장키로 호환. API 비용계산·JSON저장·기존차트 링크 유지.
실제 Astryx Layout/Stack/Grid/Card/Text/Button/ToggleButton/Dialog/Selector/CheckboxInput/NumberInput 등을 사용한다. 색·간격·상태·포커스는 라이브러리 테마/props, 별도 커스텀CSS 없음. 위치·가운데정렬 등에 한정된 inline style3개는 doctor 경고로 기록.

## 빌드·배포 계약
Python 카드 빌드 다음 `build_artifact.py`가 `build_ui.mjs`(esbuild)를 호출. 데이터/JS/CSS/폰트를 main HTML에 모두 포함. Figtree는 @fontsource 패키지에서 로컬번들하고 테마의 외부폰트import는 esbuild plugin에서 대체. 실제렌더 외부HTTP요청0 확인.
새메인 artifact/llm-radar.html, 이전차트 artifact/llm-radar-legacy.html. Pages 워크플로는 index.html과 legacy HTML을 함께 복사한다. 운영배포 미실행.

## 검증
새 UI 탐색·검색·선택비교·다운로드·제작사저장/재로드/취소·빠른답변품질조건·모바일너비 회귀. 기존 기능은 legacy 파일에서 별도 회귀.
Node70/Python11 통과. doctor --built artifact/llm-radar.html: fail0, --built web: fail0. 경고: 생성된 테마 메타데이터의 외부Figtree 로딩을 정적으로 증명하지 못함(실제번들·실행외부요청0으로 별도검증), 제한적인 inline style3개.
모바일390px overflow0. 애니메이션완료 후 Dialog 배경white/opacity1, 화면내 위치 확인. 시각적 만족도는 사용자 평가 대기이며 테스트 통과로 증명된 것은 아니다.
